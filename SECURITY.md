# Security policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch of [my3w-98/heic-convert](https://github.com/my3w-98/heic-convert).

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email or message the maintainer via GitHub: [my3w-98](https://github.com/my3w-98)

Include:

- A description of the issue
- Steps to reproduce
- Impact assessment if you have one

You should receive an acknowledgement when the report is seen. Please allow reasonable time for a fix before any public disclosure.
