# Contributing to HEIC Convert

Thanks for helping improve HEIC Convert. This project is maintained on GitHub at [my3w-98/heic-convert](https://github.com/my3w-98/heic-convert) and released under the **GNU GPLv3**.

## How to contribute

1. Fork the repository on GitHub
2. Clone your fork
3. Create a branch for your change
4. Set up a local environment:

   ```bat
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

5. Make your changes and test the GUI (`HEIC Convert.bat` or `app.py`)
6. Open a pull request against `main`

## Guidelines

- Keep changes focused and easy to review
- Match the existing code style
- Do not commit `.venv/`, converted images, or personal files
- By contributing, you agree that your contributions are licensed under the **GNU General Public License v3.0** (or later), the same license as the project

## Reporting bugs

Open an issue at https://github.com/my3w-98/heic-convert/issues and include:

- Windows version
- Python version
- Steps to reproduce
- What you expected vs what happened
